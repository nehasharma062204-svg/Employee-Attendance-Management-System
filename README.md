Employee Attendance Management System

A simple Employee Attendance Management System built using Python, Streamlit, and SQLite.

Features

- Add Employee
- View Employees
- Search Employee
- Update Employee Salary
- Delete Employee
- Mark Attendance
- View Attendance History

Technologies Used

- Python
- Streamlit
- SQLite

Installation

pip install -r requirements.txt
streamlit run app.py

Project Structure

- "app.py" - Streamlit frontend
- "employee_system.py" - Backend and database operations
- "attendance.db" - SQLite database
- "requirements.txt" - Project dependencies

How to Use

1. Add employee details.
2. Mark attendance.
3. View employee records.
4. Update salary details.
5. View attendance history.
